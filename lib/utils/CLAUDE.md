# Music Player Controls Implementation

## 개선 사항 (Improvements)

하단 음악 플레이어의 비활성화된 버튼들에 기능을 구현했습니다.

### 1. 셔플 (Shuffle) 버튼
- **기능**: 재생목록의 곡 순서를 무작위로 재생
- **동작**:
  - 클릭 시 셔플 모드 활성화/비활성화 토글
  - 활성화 시 버튼이 청록색(#39c5bb)으로 표시
  - 다음 곡 재생 시 재생목록에서 무작위로 선택

### 2. 이전 곡 (Skip Back) 버튼
- **기능**: 이전 곡으로 이동 또는 현재 곡 재시작
- **동작**:
  - 현재 재생 시간이 3초 이상이면 → 현재 곡을 처음부터 재생
  - 3초 미만이면 → 재생목록의 마지막 곡을 재생
  - 이전 곡이 없으면 현재 곡을 처음부터 재생

### 3. 다음 곡 (Skip Forward) 버튼
- **기능**: 재생목록의 다음 곡으로 이동
- **동작**:
  - 셔플 모드: 재생목록에서 무작위 선택
  - 일반 모드: 재생목록의 첫 번째 곡 재생
  - 재생목록이 비어있으면 비활성화

### 4. 반복 (Repeat) 버튼
- **기능**: 반복 재생 모드 설정
- **3가지 모드**:
  - `off` (반복 없음): 재생목록이 끝나면 정지
  - `all` (전체 반복): 재생목록이 끝나면 처음부터 다시 재생
  - `one` (한 곡 반복): 현재 곡을 계속 반복 재생
- **UI 표시**:
  - 반복 모드 활성화 시 버튼이 청록색으로 표시
  - `one` 모드일 때 버튼 중앙에 "1" 표시

## 사용자 경험 개선

### 직관적인 UI
- 활성화된 기능은 청록색으로 표시되어 쉽게 구분 가능
- 반복 모드가 "한 곡 반복"일 때 숫자 "1" 표시로 명확한 피드백

### 스마트한 동작
- 이전 곡 버튼: 3초 기준으로 현재 곡 재시작 vs 이전 곡 재생 결정
- 반복 모드와 셔플 모드의 조합 지원
- 빈 재생목록 상태 처리

### 상태 지속성
- 셔플/반복 설정이 세션 전체에 걸쳐 유지됨
- 사용자가 설정을 다시 할 필요 없음

## 테스트 시나리오

1. **셔플 모드 테스트**
   - 재생목록에 여러 곡 추가
   - 셔플 버튼 클릭하여 활성화
   - 다음 곡 버튼으로 무작위 재생 확인

2. **반복 모드 테스트**
   - 반복 버튼을 클릭하여 모드 순환 확인 (off → all → one)
   - 각 모드에서 곡이 끝날 때 동작 확인

3. **이전 곡 버튼 테스트**
   - 곡 재생 시작 직후(3초 미만) 클릭 → 이전 곡 재생
   - 곡 재생 중(3초 이상) 클릭 → 현재 곡 재시작

4. **조합 테스트**
   - 셔플 + 전체 반복: 무작위 순서로 계속 재생
   - 셔플 + 한 곡 반복: 현재 곡만 반복 (셔플 무시)
